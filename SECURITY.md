# Security Policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not open a public issue
for API-key exposure, path traversal, unsafe external navigation, renderer privilege escalation, or
document-content leakage.

Include the affected version, reproduction steps, expected impact, and any suggested mitigation.
Please do not include real API keys or personal documents in the report.

## Supported version

Security fixes target the latest published release.
